# 插件测试用例全覆盖-开发计划

- **日期**：2026-09-07
- **目标**：对照 mybatis-plus-sql-visualizer 插件的 SQL 提取能力清单，补齐 demo 三个子项目缺失的代码场景，使插件的核心功能（gutter 图标、SQL 预览、参数回填）都有真实测试语料。
- **范围**：仅 demo 项目，不改插件代码。所有新代码以「插件覆盖矩阵 ✅ 项」为语料来源，编译通过为硬门禁。

## 一、现状盘点（缺口分析）

以插件三份覆盖矩阵（MP-MPJ / JPA-Hibernate / 其他ORM）逐项对照现有 demo 代码：

### mybatis-plus-demo（MP 3.5.2 → 升级 3.5.3.1）

| 场景 | 现状 | 缺口 |
|------|------|------|
| 条件方法 | eq/ne/gt/ge/le/like/likeRight/in/between/isNull/last/apply/exists/notExists/inSql/notInSql/gtSql/leSql/nested/not/allEq/groupBy/having/orderBy 已覆盖 | likeLeft/notLike 族、notBetween、isNotNull、geSql/ltSql、func、applyFunc、first/comment、or 嵌套细节、多列 groupBy/orderBy |
| 工厂形态 | Wrappers 少量 | Wrappers 全 5 工厂、ChainWrappers 链式终结点、Db kit、SimpleQuery、ActiveRecord（Model） |
| CRUD 全形态 | 部分 | selectMapsPage/selectCount/exists/remove(Wrapper)/removeByMap/page/pageMaps/update(Wrapper) 等 |
| 实体注解 | @TableName/@TableId/@TableField/@TableLogic/@Version | @KeySequence、@EnumValue、@OrderBy、@SqlCondition |
| Mapper XML | 仅 UserMapper.xml（if/foreach/choose/trim/set/bind/include 已有） | **`${ew.customSqlSegment}` 展开（0 处）**、其余 Mapper 无 XML |
| 注解 SQL | @Select/@Insert/@Update/@Delete + script | **Provider 族（@SelectProvider 等）0 处** |

| 场景 | 现状 | 缺口 |

## 二、API 可用性核验（javap 本地 jar 权威）

- MP 3.5.3.1（本地缓存）：`Db`、`SimpleQuery`、`first/comment/func/notLike 族/exists/notExists` ✅；`eqSql/selectIgnore/setIncrBy/setDecrBy` ❌ 不存在 → **不写**（需 MP 3.5.4+，另行升级再补）。
- MPJ 1.5.8：`MPJLambdaWrapper.selectAs/selectAsClass/selectCount/selectFunc/selectSub/distinct/selectAll/selectFilter`、`CompareIfExists/CompareStr/QueryJoin` 接口族、`com.github.yulichang.query.MPJQueryWrapper`、union/unionAll/from ✅；`selectSum/Max/Min/Avg/Len` 1.5.8 无（1.5.9+）→ **不写并标注**。
- 插件明确不支持（写了对插件无意义）：UPDATE JPQL、CriteriaUpdate/Delete、裸 findAll CRUD、其他 ORM → **不写**。
- 最终以 `mvnd compile` 为门禁：任何 API 不存在即编译失败，当场修正。

## 四、风险与约束

- **版本墙**：eqSql/selectIgnore（MP≥3.5.4）、setIncrBy/setDecrBy（MP≥3.5.6）、selectSum 族（MPJ≥1.5.9）本轮不写，待整体升版再补，避免破坏现有编译。
- **插件盲区不写**：写了对插件无意义的场景会污染语料（见上「插件明确不支持」）。
- **不改既有行为**：新增独立 Service/Mapper/实体为主，现有文件仅做必要扩展（Mapper 接口加方法、UserMapper 加 Provider 注解）。
- **编码**：全部 Java 8 语法（demo 目标 JDK 1.8）。

3. 新场景在 IDEA 中打开能看到对应 gutter 图标（人工抽验项，写入 README 供测试对照）。
