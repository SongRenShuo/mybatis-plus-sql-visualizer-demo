## 四、风险与约束

- **编译门禁**：每里程碑 `mvnd compile` 零错误才提交；新 API 先 javap 后落笔（第二节全部实证在案）。
- **jakarta 3.1.0 陷阱**：字节码 major 55，绝不能用（3.0.0 为 52）；依赖显式锁版本。
- **SD 桩注解**：本地建 `org.springframework.data.relational.*` 包属于**有意为之的语料桩**（模拟真实项目 classpath 有 SD jar 的 PSI 形态），类 javadoc 必须标明；后续若 jpa-demo 升 Boot 3 线须删桩换真依赖。
- **混合实体运行边界**：MP 3.5.7 运行期不解析 jakarta 注解，混合实体语料定位为静态预览（类注释明示勿 curl）；避免被误当运行回归用例。
- **内联 XML 变体根元素名**：避开 mapper/pages/hbm 已认领根名，防双图标对照失真。
- **LogFeeder 打印格式**：SS 双段按插件解析器文档形态（`Logic SQL:` / `Actual SQL: ds_x ::: ... ::: Parameters: [..]`）打印；插件侧注明真实语料未采样，若后续真 ShardingSphere 日志形态有差，语料端再校正。
- **schema.sql 同步**：新增实体逐列对齐（README 既有约定）。
